# ngumbah-platform

Entry point for **Ngumbah**, a multi-tenant laundry POS SaaS built as a set of microservices.

This repository holds the local development platform: infrastructure (Docker Compose, OpenTofu against a local AWS emulator), the bootstrap script that clones every service repository, and the architecture overview.

Planning and phase specs are tracked as issues in this repository.

## Status
